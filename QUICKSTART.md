# Быстрый старт

## Минимальные шаги для запуска

### 1. Установка зависимостей
```bash
cd cinema_booking
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или venv\Scripts\activate для Windows
pip install -r requirements.txt
```

### 2. Запуск БД и Redis
```bash
docker-compose up -d
```

### 3. Настройка окружения
```bash
cp .env.example .env
```

### 4. Инициализация БД
```bash
flask --app app init-db
```

### 5. Запуск приложения
```bash
python app.py
```

### 6. Открыть в браузере
http://localhost:5000

## Тестирование функционала

1. Выберите любое событие на главной странице
2. Кликните на свободные места (они станут синими)
3. Заметьте таймер - у вас есть 5 минут
4. Заполните форму и нажмите "Забронировать"
5. Откройте страницу в другом браузере/вкладке - увидите, что места заняты

## Что происходит под капотом

- **Redis** хранит временные блокировки с TTL 5 минут
- **PostgreSQL** хранит окончательные бронирования
- **Транзакции** защищают от двойного бронирования
- **Сессии** различают пользователей
- **Автообновление** показывает статус мест каждые 3 секунды

## Остановка

```bash
# Ctrl+C для остановки Flask
docker-compose down  # Остановка БД и Redis
```
